# Hotel Booking System

A console-based Hotel Booking System built using Java, JDBC, MySQL, and Maven.

## Features

- Book a room
- View a booking by ID
- View all bookings
- Update booking details
- Delete a booking

## Tech Stack

- Java
- JDBC
- MySQL
- Maven
- MySQL Connector/J

## Setup

1. Install Java, MySQL, and Maven support through IntelliJ IDEA.
2. Create a MySQL database named `hoteldb`.
3. Create the `booking_table` with the required columns: `id`, `name`, `phone_number`, `timestamp`, and `room_number`.
4. Configure the database URL, username, and password for your local environment.
5. Open the project in IntelliJ and reload Maven dependencies.
6. Run `HotelBookingApp.java`.

## Learning Objectives

This project demonstrates JDBC connectivity, SQL CRUD operations, prepared statements, result sets, and exception handling.
